# Vocabulary Flashcard Spaced Repetition Trainer
Create custom flashcard decks and study them using the Leitner box spaced repetition system for efficient memorization.
## Features
- Create multiple named decks with term, definition, and optional notes per card
- Leitner 5-box system: Box 1 daily, Box 2 every 2 days, Box 3 every 4 days, Box 4 weekly, Box 5 mastered
- Animated flip cards — rate each card Easy (advance box) or Hard (reset to Box 1)
- Progress dashboard showing cards per box and due count per deck
- CSV import mode: paste "term,definition" lines to bulk-add cards
## Usage
Create a deck, add cards manually or via CSV import, then click "Study Now" to review all due cards. Rate each card after flipping to control its review schedule.
